# FeelFilm — бот автопостинга для ВКонтакте

Python-бот, который автоматически публикует качественные посты о кино в
сообществе **FeelFilm** во ВКонтакте: новинки, премьеры, рекомендации и
интересные факты. Материал берётся из Kinopoisk API, текст генерируется ИИ
(с шаблонным запасным вариантом), к посту прикрепляется официальный постер.

## Возможности

- 📅 Полностью автоматическая работа по расписанию (по времени или интервалу).
- 🎬 Источник новостей — Kinopoisk (премьеры, новинки, популярное, трейлеры).
- 🤖 Генерация уникального текста ИИ: заголовок, описание без спойлеров,
  основные сведения, вопрос для вовлечения аудитории.
- 🖼️ Прикрепление официального постера.
- 🔁 Дедупликация — одна и та же новость не публикуется дважды.
- 🧩 Несколько типов контента: премьера, рекомендация, подборка, факт.
- 📝 Журналирование в файл с ротацией.
- ⚙️ Все настройки — в одном `.env`, модульная архитектура для расширения.

## Структура проекта

```
vk_bot/
├── main.py           # точка входа и сборка пайплайна
├── config.py         # загрузка и валидация настроек (.env)
├── vk_client.py      # VK API: wall.post + загрузка фото
├── news_fetcher.py   # источники новостей (Kinopoisk) + выбор материала
├── content_types.py  # типы контента (премьера/рекомендация/факт…)
├── ai_generator.py   # генерация текста (OpenAI-совместимый + шаблон)
├── image_handler.py  # скачивание постеров
├── scheduler.py      # планировщик публикаций
├── posted_store.py   # хранилище опубликованного (дедупликация)
├── logger.py         # настройка логирования
├── requirements.txt
├── .env.example
└── data/             # posted.json и bot.log (создаётся автоматически)
```

## Установка

```bash
cd vk_bot
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

## Настройка

1. Скопируйте пример конфигурации и заполните значения:

   ```bash
   cp .env.example .env
   ```

2. **Токен сообщества ВКонтакте** (`VK_TOKEN`):
   - Откройте сообщество → **Управление** → **Работа с API** → **Ключи доступа**.
   - Создайте ключ с правами **Стена (wall)** и **Фотографии (photos)**.
   - Скопируйте токен в `VK_TOKEN`.

3. **ID сообщества** (`VK_GROUP_ID`): числовой ID без минуса.
   Если у сообщества короткий адрес, ID можно посмотреть в
   **Управление → Адрес страницы**, либо через `vk.com/dev`.

4. **Ключ Kinopoisk** (`KINOPOISK_API_KEY`): тот же, что использует backend
   приложения (`kinopoiskapiunofficial.tech`).

5. **ИИ** (по желанию):
   - `AI_PROVIDER=template` — работает сразу, без ключей: аккуратный пост
     собирается из данных о фильме.
   - `AI_PROVIDER=openai` — включает генерацию через OpenAI-совместимый API.
     Задайте `AI_API_KEY`, при необходимости поменяйте `AI_BASE_URL` и
     `AI_MODEL` (подходят OpenAI, OpenRouter, локальный Ollama, прокси GigaChat
     и др.). Если ИИ временно недоступен, бот автоматически откатывается на
     шаблон.

## Проверка перед запуском

```bash
# Проверить конфиг и токен (имя сообщества выведется в лог):
python -m vk_bot.main --check

# Прогон без реальной публикации — покажет готовый текст поста:
python -m vk_bot.main --once --dry-run
```

## Запуск

```bash
# Один пост прямо сейчас:
python -m vk_bot.main --once

# Демон по расписанию (из POST_TIMES / INTERVAL_HOURS):
python -m vk_bot.main
```

> Запускать нужно из корня репозитория как модуль (`python -m vk_bot.main`),
> чтобы работали относительные импорты пакета.

## Автозапуск на сервере

**Linux (systemd)** — создайте `/etc/systemd/system/feelfilm-vkbot.service`:

```ini
[Unit]
Description=FeelFilm VK autoposting bot
After=network-online.target

[Service]
WorkingDirectory=/opt/feelfilm
ExecStart=/opt/feelfilm/vk_bot/.venv/bin/python -m vk_bot.main
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now feelfilm-vkbot
journalctl -u feelfilm-vkbot -f
```

**Windows (Планировщик заданий)** — создайте задачу, которая запускает
`python -m vk_bot.main` из папки репозитория при входе в систему.

## Как расширять

- **Новый источник новостей** — унаследуйтесь от `NewsSource` в
  `news_fetcher.py`, реализуйте `fetch()`/`enrich()` и добавьте экземпляр в
  список `sources` в `main.py`.
- **Новый тип контента** — добавьте запись в `CONTENT_TYPES`
  (`content_types.py`) и, при необходимости, стратегию выбора материала.
- **Другой стиль текста** — правьте промпты в `ai_generator.py`.

## Примечания

- Файлы `.env` и `data/` не коммитятся (см. `.gitignore`).
- Дедупликация хранится в `data/posted.json` — удалите запись оттуда, если
  нужно опубликовать материал повторно.
- Бот публикует по одному посту за запуск задачи; частота задаётся расписанием.
